# Исправление сжатого правового блока — 28.10.2026

URL: https://tangerin.ru/#documents-and-contacts . Ошибка подтверждена скриншотом пользователя и воспроизведена в настоящем браузере. Прежнее утверждение о готовности компактного footer было преждевременным: статическая проверка типографики ссылок не проверила внешнюю сетку.

Причина: новый HTML содержит заголовок и вложенную `.compact-legal-columns`, но внешний `.site-legal` сохранил старый `display:grid` с двумя колонками. Внутренний блок попадал только в правую ячейку. При общей ширине1200px внешний grid давал796.5px заголовку и383.5px контактам/документам; после вложенного деления документам оставалось139.5px. Высота достигала446.5px. Это дефект текущей вёрстки, не предположение о кеше пользователя.

Исправление: внешний блок `display:block`, заголовок на всю ширину, под ним общая строка контактов и документов. Документы в2 колонках desktop и1 колонке<=700px; ссылки14px, без карточек/рамок. Контакты/6 ссылок/служебная фраза сохранены. Изменение ограничено `.client-compact-legal`; CMS/JS/документы не изменялись.

Проверка выполнена через доступный Orca CLI / встроенный браузер, без нативного управления окнами.
