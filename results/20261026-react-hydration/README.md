# React #418 — исправление26.10.2026

Страницы проверки: https://tangerin.ru/ и https://tangerin.ru/vse-dlya-otdyha/s-detmi .

Ошибка повторно воспроизведена на полной загрузке главной до изменения. React#418 обозначает несовпадение HTML при гидратации: https://react.dev/errors/418 . React требует одинаковой исходной разметки сервера и браузера: https://react.dev/reference/react-dom/client/hydrateRoot .

Найден конфликт жизненного цикла: `syncEmbeds()` при сохранённом согласии добавлял iframe Яндекса внутрь React-контейнера карты сразу после загрузки настроек cookies. Он не проверял завершение гидратации. React ожидает только placeholder, а при раннем ответе API находит дополнительный iframe. После временного выключения внешних виджетов2 повторные загрузки не добавили ошибок; исходные настройки пользователя восстановлены (оба разрешения включены).

Исправление: серверная и клиентская разметка карты/отзывов содержат одинаковый маркер `data-tangerin-react-embed`. Ref-callback после commit ставит `data-tangerin-hydrated` и уведомляет контроллер в microtask; до этого момента он не изменяет React-контейнер. При callback повторно проверяются connected-state и текущее согласие. Для CMS-контейнеров прежнее поведение сохранено. React/framework не патчились, ошибки не подавлялись, произвольная задержка не добавлялась. CSS, тексты, CMS, UID и SDK Bnovo не менялись.
