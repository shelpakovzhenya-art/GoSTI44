# Bnovo: восстановление загрузки — 29.10.2026

Опубликовано на https://tangerin.ru/ и внутренних страницах, включая https://tangerin.ru/vse-dlya-otdyha/zavtraki .

## Причина и изменение

Старый загрузчик сохранял неудачно загруженный script и при повторе ожидал уже прошедшее событие load. Наличие iframe считалось успехом даже без полей. Поведение старого кода воспроизведено тестом. На исходном живом сайте форма в момент проверки работала; конкретный сетевой сбой со скриншота клиента не воспроизведён.

Новый общий загрузчик проверяет заполненные поля дат/гостей и кнопку поиска. Один запрос SDK обслуживает обе формы главной. Ошибка/таймаут SDK6с удаляет неудачный script; пустой iframe после9с пересоздаётся. Не более3 автоматических попыток, затем ручной повтор; при восстановлении сети — новая попытка. Через2,5с медленной загрузки доступна прямая ссылка существующего модуля. В исправном состоянии дополнительные элементы скрыты. Поздние ответы отменённых попыток игнорируются, обработчики/таймеры очищаются при переходах. Введённые посетителем даты не сбрасываются при изменении ширины.

Существующий UID, официальный SDK, параметры формы и путь оформления сохранены. Настройки кабинета, тарифы, уведомления и данные заказов не изменялись. Новые брони/платежи не создавались.

## Ограничения

Доступность стороннего Bnovo и сети посетителя гарантировать нельзя. Резервная ссылка помогает при сбое встроенной формы, но использует тот же сервис и не заменяет его при полном отказе. Доставка новой брони/уведомления в кабинет в этой задаче не тестировалась.

Код: `booking-manager.js`, `footer-loader.js`, `home-effect.js`. Подготовка/проверки: `prepare.py`, `apply-runtime.py`, `verify-server.py`, `finalize.py`, `test-recovery.cjs`. Для повторного применения нужна свежая проверенная сборка; старый план не применять поверх дальнейших изменений.
