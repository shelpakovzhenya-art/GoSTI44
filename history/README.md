Исходный чат, его вложения и история остаются в приложении Codex / ChatGPT на этом компьютере. Они не удалялись, не архивировались, не перемещались и не обрезались.

Новые чаты Orca начинают отдельные задачи и читают актуальный контекст проекта. Если нужен конкретный старый факт, сначала искать его в каноническом handoff и связанных итоговых файлах; затем точечно читать соответствующий старый фрагмент. Не загружать весь многомесячный журнал в новый чат.

При необходимости Orca умеет читать существующие локальные Codex-сессии через Agent Session History. Одновременно продолжать одну и ту же исходную сессию из двух приложений не следует. В этой настройке исходные сессии не захватывались режимом Resume.
