# Актуальная база Танжерина

20.10.2026 по запросу владельца зафиксировано фактическое состояние `https://tangerin.ru/` после изменений с другого устройства. Каноничны production и проверенные копии в этой папке.

## Состав

- `runtime/`: работающая standalone-сборка, её JS/CSS, фотографии, видео, шрифты и зависимости. Это compiled runtime, а не восстановленный TypeScript-проект.
- `cms-source/`: 152 файла актуального серверного кода CMS и публичных assets. `.env`, кеш конфигурации, БД, пользователи, сессии и приватное storage не копировались.
- `public-evidence/`: опубликованный CMS JSON, sitemap, robots, llms, HTML, DOM-инвентарь и screenshots всех 17 страниц на ПК/телефоне.
- `runtime-manifest.json`, `cms-source-manifest.json`, `snapshot.json`: контрольные суммы и происхождение снимка.
- `history/`: прежний локальный контекст; исторические описания не переопределяют текущий production.

Имя серверного релиза осталось сентябрьским, но код/стили изменялись на месте вплоть до 19 октября. GitHub main заканчивается 28 сентября и не равен production. Нельзя использовать старую локальную сборку для следующих правок или считать обычный `git pull` синхронизацией с продом.

Снимок проверен по содержимому всех файлов; публичный CMS JSON также совпал с сервером по SHA-256. Будущие изменения — от свежих production-файлов с проверкой затронутых хешей и сохранением отката.
