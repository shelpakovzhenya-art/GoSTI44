# Web Kit v0.12.0

## Что изменилось

- Новая SEO-статья проходит восемь отдельных этапов. Следующий этап запускается только по явной просьбе пользователя и получает короткий handoff.
- Research и фактчек разделены: `$article-researcher` собирает доказательную базу, а `$article-fact-checker` допускает в план и текст только разрешённые утверждения.
- Kit устанавливает эти две skills и полный `$humanizer-ru` с MIT-лицензией, reference-файлами, lint и SEO guard.

## Границы

- Первоисточники и клиентские данные важнее пересказов. Экспертное видео требует URL и таймкод. Отзывы, комментарии и форумы остаются сигналами вопросов аудитории.
- Humanizer сохраняет структуру, ключи, FAQ, CTA, ссылки и объём 95–105%; ошибка проверок блокирует этап.
- Существующие статьи, local overrides, сайт, Git и Google Docs не меняются при установке release.
