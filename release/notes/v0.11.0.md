# Web Kit v0.11.0

Web Kit теперь по умолчанию отвечает кратко и создаёт человекочитаемые документы на русском языке. Технические названия, пути, команды, код, API и машинные стадии сохраняются без перевода.

## Что изменилось

- Короткий статус или локальная правка обычно укладываются в 120 слов, а резюме крупного этапа — в 200 слов.
- Убраны обязательные повторы результата, пользы, следующего шага, причины, команды и служебного пути. Неприменимые разделы можно не выводить.
- Правило русского языка распространяется не только на чат, но и на новые отчёты, планы, исследования и спецификации.
- Все 101 `Output`-контракта получили единое требование к русскому и краткому человекочитаемому результату.
- Основные шаблоны состояния, брифа, страницы, блока, checkout, e-commerce и gpt-taste переведены и сокращены.
- Новый снимок состояния ограничен 4 КБ. При будущем сокращении старый текст сначала сохраняется без потерь в локальной истории; во время установки релиза существующие документы не меняются.

## Что осталось без изменений

- Маршруты, пути промптов, updater schema v1 и машинные названия стадий совместимы с 0.10.2.
- CMS-, security-, secrets-, Next.js-, commerce-, SEO-, accessibility-, design- и release-gates не ослаблены.
- Обновление не переводит и не переписывает существующие `docs/**`, исходники сайта, локальную часть `AGENTS.md`, Git-ветки или remotes проекта.

## Проверка

- Статические проверки контролируют размеры обязательных инструкций, язык шаблонов, 101 выходной контракт, ссылки и состав релиза.
- Десять маршрутизационных сценариев должны пройти 10/10.
- Шесть сценариев общения проверяют русский язык, краткость и понятное действие пользователя.

Релиз остаётся публичным и распространяется по лицензии MIT.
