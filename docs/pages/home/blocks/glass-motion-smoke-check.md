# Стеклянная шапка, эмблемы домов и появление блоков — 09.09.2026

Статус: passed для локальных изменений.

## Реализация

- По запросу пользователя шапка получила матовое стекло: прозрачные слои, blur 24 px, насыщенность фона, светлый контур и внутренний блик. Сохранены читаемые тёмные надписи. Предусмотрены непрозрачный fallback и prefers-reduced-transparency.
- Оригинальные SVG-эмблемы: зелёный лайм с разрезом, жёлтый лимон с листьями, оранжевый цитрус с разрезом. Используются на фото, рядом с названием и в подробностях дома. Декоративные SVG скрыты от скринридеров; градиенты имеют уникальные React useId.
- В нижней строке футера добавлены Telegram и ВКонтакте из опубликованных настроек CMS. Ссылки и доступные подписи переиспользованы из ContactLinks.
- Референс движения: https://rodina-beautybar.ru/, просмотрен в браузере; исследованы фактические data-reveal transitions и локальный scroll-experience. Адаптация: блоки входят снизу с мягким замедлением, карточки с небольшим увеличением до исходного размера. На desktop задержки 0/75/150 ms. Скролл остаётся нативным.
- IntersectionObserver и Web Animations API, без дополнительных зависимостей и перерисовок React при скролле. Первый экран не скрывается после hydration. Cleanup отменяет наблюдение и анимации. Фокус открывает ожидающий блок; reduced motion отключает все появления, включая смену системной настройки во время просмотра. Без JavaScript контент виден.

## Проверка

- Реально просмотрены скриншоты: 1440×1000 (шапка, карточки, футер), 390×844 (шапка, меню, дом, футер), 2560×1440 (шапка и карточки), 320×780 (шапка). Изображения находятся локально в `.local-runtime/glass-motion/`, исключены из Git.
- Общая фотографическая подача, бренд, размеры контентной колонки и реальные фотографии сохранены. На wide три карточки остаются примерно по 411 CSS px; на mobile нет обрезанных элементов и горизонтального переполнения. Эмблемы различимы, стекло заметно на фотографии и сохраняет читаемость на светлых секциях.
- Открытие/закрытие меню, Escape, открытие дома, ArrowRight для фото, закрытие диалога и возврат фокуса проверены. Социальные ссылки соответствуют Telegram/VK из CMS.
- Измерено реальное промежуточное состояние появления: opacity ~0.65, translateY ~20 px, одна активная анимация; после завершения opacity=1 и transform=none. На desktop подтверждены задержки 0/75/150 ms. При reduced motion ожидающих блоков и активных анимаций нет.
- После свежей загрузки runtime/hydration errors отсутствуют. Ранее HMR обнаруживал data-heading-tag, добавленный браузерной инспекцией; на свежей загрузке не воспроизводится.
- `npm run verify:content`, `npm run typecheck`, `npm run lint`, `npm run build`: passed. `php artisan test`: 9 passed, 28 assertions. Прикладной backend и опубликованный контент не менялись.
- Применена проверка React Best Practices: cleanup эффектов, уникальные SVG IDs, отсутствие лишних зависимостей и подписок на каждый scroll tick, семантика кнопок/ссылок, focus и reduced motion.

## Границы

Production не публиковался. Полный сценарий редактирования/публикации CMS не повторялся: контент и backend не изменены.
