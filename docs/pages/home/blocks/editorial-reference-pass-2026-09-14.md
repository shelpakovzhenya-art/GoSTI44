# Редакционная композиция главной — 14.09.2026

## Результат

- Главная приведена к спокойной тёплой подаче из референса: крупные зелёные антиквенные заголовки, тонкие рамки, кремовые поверхности и заметное растительное обрамление по краям.
- Цитрусовые ветви, ветви с лимонами и пальмовые листья чередуются между главами и обрамляют контент с двух сторон. На мобильном декор частично уходит за край, поэтому не закрывает текст и не расширяет документ.
- Блок преимуществ собран в компактный ряд из восьми пунктов. Повторная большая фотография в нём удалена, чтобы следующая глава бани начиналась как самостоятельная композиция.
- Баня объединена в одну рамочную композицию: два настоящих снимка объекта и текст находятся внутри общего светлого блока.
- Четыре услуги собраны в сетку 2 × 2 с настоящими фотографиями объекта. Фотография принадлежит записи услуги в CMS и меняется через вкладку «Фотографии».
- Бронирование сведено в одну общую поверхность без отдельной вложенной карточки.
- Блок «Перед бронированием» больше не состоит из пустого левого поля и отдельного аккордеона: текст, контакт, фотография и вопросы объединены в один блок.
- Удалены тени у основных карточек; разделение строится на цвете поверхности, фотографии, рамке и ритме.
- Анимационные селекторы обновлены под фактические компоненты, без ссылок на удалённую разметку.

## Контент и CMS

- Каждая услуга обязана иметь заголовок, описание, подробности, допустимые иконку/оформление и минимум одну фотографию с alt.
- Миграция добавляет фотографию отдельно в draft и published, не перезаписывает редакторские различия и создаёт ревизию для каждого изменения.
- Используются только существующие реальные фотографии «Танжерина»; вымышленные изображения объекта и новые факты не добавлялись.

## Проверки

- Desktop 1440 px: все основные главы просмотрены по отдельности.
- Mobile 390/320 px: преимущества, баня, услуги, бронирование и FAQ просмотрены по отдельности.
- На 1440/390/320 px `scrollWidth` совпадает с шириной окна, принудительный горизонтальный скролл равен нулю.
- Ошибок выполнения и Next error overlay нет.
- `npm run verify:content`, `npm run typecheck`, `npm run lint`, `npm run build`.
- Полный набор тестов CMS, включая сохранение draft/published и обязательные фотографии услуг.
