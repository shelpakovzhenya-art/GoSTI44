# Быстрая проверка: читаемость, декор, шапка и футер

## Вердикт

Passed для локального просмотра дизайна. Публикация и полный backend не входят в эту проверку.

## Исправления по визуальной проверке

1. Текст 11–14 px и тесные сетки заменены более крупными размерами и адаптивными колонками.
2. Мандарин, перекрывавший подпись к веранде, перенесён за фото; лимонная ветвь помещена в безопасную область верхнего угла.
3. Iframe карты наследовал flex-basis:0 и сжимался до 150 px. Теперь flex:none и заданная высота 475/380 px.

## Проверенный интерфейс

- 390 CSS px: шапка, hero, услуги, контакты, реально загрузившийся iframe Яндекса; overflow отсутствует (scrollWidth 375 с системной полосой прокрутки).
- 1440 CSS px: hero, три карточки домов, преимущества и footer; карта 475 px, данные организации совпадают с действующим сайтом (телефон и ссылка клиента).
- 2560 CSS px: блок преимуществ и переход к SPA; контейнер ограничен 1400 px, текст и фото остаются связаны. Декор не закрывает текст, контейнер не растягивается до ширины экрана.
- 1024 CSS px: горизонтальные карточки домов (примерно 456/481 px), шапка 93 px, overflow отсутствует.
- Дополнительно 330 CSS px: карточки услуг помещаются в доступную ширину, иконки шапки видимы, телефон скрывается для свободного места.
- Стабильная CSS-компоновка без viewport-dependent React веток. Изображения зарезервированы по размерам, реальные фотографии сохранены.
- Мобильное меню: переход к услугам закрывает меню и устанавливает aria-expanded=false.
- Услуги: описание завтраков раскрывается по «Подробнее».
- Диалог дома «Лайм»: открытие, данные, Escape и возврат фокуса к кнопке.
- Маршрут в Яндекс Картах: открывается форма маршрута, конечный пункт — координаты существующей карточки. Отправная точка не задавалась. Никаких сообщений клиенту или бронирований не отправлялось.
- После свежей перезагрузки проверяемой вкладки ошибок console нет. Исторические ошибки dev HMR при смене CSS остались в журнале, на свежем документе не воспроизводятся.

## Технические команды

ESLint, verify:content и production build с TypeScript / static export завершились успешно. Проверка контента: 17 реальных ассетов, 4 декоративных ассета, 10 якорей, 3 площадки карт и 23 слова цитат. После этого только незначительные CSS правки проверялись браузером.
