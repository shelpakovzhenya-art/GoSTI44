# Локальная проверка Tangerine — 07.09.2026

Статус: локальный лендинг «Танжерин» открыт для согласования дизайна по http://127.0.0.1:3107/ . Публичное название исправлено после уточнения пользователя в шапке, подвале, текстах, metadata, alt и 404.

## Проверено

- `npm install`: зависимости установлены, lockfile создан, audit — 0 vulnerabilities.
- `npm run lint`: успешно.
- `npm run build`: успешно, включая TypeScript и статический экспорт в `out`.
- `npm run verify:content`: 15 ассетов, 7 разделов, 3 карточки карт, 23 слова цитат.
- Реальный браузер CUA: первый экран 390×844, 1440×1000 и 2560×1440. Горизонтального overflow нет. Логотипы площадок и фото отображаются; brokenImages = 0 при итоговой проверке.
- Карточка «Люкс»: открытие, описание, следующее фото; закрытие Escape возвращает фокус кнопке открытия. Галерея: переход с 1/5 на 2/5, Escape, возврат фокуса.
- Мобильное меню: раскрытие, переход к домам, закрытие после выбора пункта; якорь расположен ниже шапки. Просмотрена мобильная карточка дома.
- Официальные отзывы Яндекса, модуль ReservationSteps и карта Яндекса загрузились внутри iframe. Брони, оплаты и сообщения не создавались. Внешний модуль Bnovo выдал предупреждение Sentry о tracing; собственных runtime errors в проверенном сценарии нет.
- После QA override размера экрана сброшен, сайт оставлен на первом экране в видимой вкладке.

## Границы готовности

Это проверка локального лендинга для согласования дизайна. Сквозной заказ и платёж не проверялись. Восемь страниц, Laravel + Filament, свой календарь и платежные webhooks отсутствуют. Существующее бронирование встроено с ссылкой для открытия отдельно.

Официальные карточки карт и сервис бронирования пока используют старое название: внешний контент не подменяется. Перед публикацией уточнить адрес 47/45А, вместимость 24/25, условия и юридические материалы, согласовать ребрендинг внешних сервисов. Индексация тестовой версии закрыта.

Storage Enforce после установки: 76,179 ГиБ; завершился с предупреждением о превышении исходного лимита. Временное превышение разрешено пользователем в этом ходе. Защищённые данные сохранены.
