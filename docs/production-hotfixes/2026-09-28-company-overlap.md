# Сокращение повтора о трёх домах на главной — 28.09.2026

По просьбе пользователя на [главной](https://tangerin.ru/) оставлен один краткий блок `#company` о размещении компании до 25 человек. Его ссылка «Подробнее» ведёт на [посадочную страницу](https://tangerin.ru/dlya-bolshoy-kompanii), где сохранено развёрнутое сравнение трёх домов. Повторявшийся блок `#comfort` скрыт; его четыре заголовка/строки в опубликованной и черновой записи CMS `holiday-sections` очищены, а список `comforts.items` опубликован пустым. Так повтор не остаётся в текстовом содержимом HTML. Остальные записи CMS и посадочная не менялись.

Production работает на `/var/www/gosti/releases/20260925-2`. Для показа использован отдельный CSS URL `/_next/static/chunks/1m2h_ruasisho-company-shortened-20260928.css` с правилом `#comfort{display:none!important}`. Он подключён в пяти client-reference-manifest активного релиза. Сервис `gosti` перезапущен. Старые исходники GitHub для пересборки production не использовались.

Перед правкой сохранены приватные копии `/var/www/gosti/backups/database-20260928-before-company-shortening.sqlite` (SQLite `integrity_check=ok`) и `/var/www/gosti/backups/production-20260928-before-company-shortening.tar.gz` (прежний CSS и пять manifest). В CMS добавлены записи ревизий draft/publish для обеих изменённых записей. Резервные копии и сама база не публикуются в GitHub.

Проверено: главная и посадочная отвечают `200`; `#comfort` не содержит текста в HTML и скрыт CSS; ссылка `/dlya-bolshoy-kompanii` присутствует в `#company`; на посадочной сохранились заголовок сравнения и canonical. В браузере на ширинах 1440 и 390 px CSS применён, горизонтального переполнения и ошибок страницы нет. Для отката восстановить две записи CMS из резервной БД, шесть файлов из tar-архива и перезапустить `gosti`; всю рабочую БД целиком не подменять из-за возможных более новых изменений.
