# Логотип клиента в production — 28.09.2026

По просьбе клиента старый плодовый знак в шапке и подвале заменён рисунком из присланного файла. Попытка уменьшить вместе с ним надписи из квадратного PNG сделала их нечитаемыми. Исправлено: название и подпись в шапке и подвале выводятся HTML-текстом в читаемом размере. Вкладка браузера использует иконку, полученную из графического знака. Внешние логотипы Яндекс Карт, 2ГИС, Avito и MAX не менялись.

Прежний декоративный `<img>` CSS скрывает; собранный компонент следует привести в соответствие после восстановления исходников действующего релиза.
- CSS подключён также в `src/app/layout.tsx` для будущей сборки репозитория. Эта локальная правка не использовалась при обновлении production.
